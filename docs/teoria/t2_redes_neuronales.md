# Redes Neuronales

## introducción

- Alimentación hacia adelante (feedforward).
- Modelo de regresión para aprendizaje supervidado.
- A partir de atributos numéricos.
- Implementa esta función: $f: \mathbb{R}^m \rightarrow \mathbb{R}$ cuyos atributos de entrada son $x_1, x_2, \ldots, x_m$ son atributos numéricos.
- Las redes neuronales se construyen a partir de capas de neuronas, cada una de las cuales realiza una transformación lineal seguida de una función de activación no lineal. La salida de cada capa se utiliza como entrada para la siguiente capa.
- Así, la red neuronal calcula la función $f$ a partir de la composición de funciones lineales y no lineales.


## Perceptrón
- Es la unidad básica de una red neuronal.
